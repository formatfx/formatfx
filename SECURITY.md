# Security

FormatFX runs fully client-side — no server, no tenant connection. The
security-sensitive surface is the `src/bridge/` snippets people paste into
their SharePoint sessions, and the exported formatter JSON itself.

Found a vulnerability? Please report it privately via
[GitHub security advisories](https://github.com/formatfx/formatfx/security/advisories/new)
rather than a public issue. You'll get a response within a few days.
